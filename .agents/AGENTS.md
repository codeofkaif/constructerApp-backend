# Agent Rules

- Write minimal, production-grade code only. No boilerplate, no placeholder comments, no unused scaffolding, no example/demo code unless asked.
- Do not explain what you're about to do before doing it. Just write or edit the code directly.
- After making a change, reply in 1-2 lines max. No summaries, no restating the task, no "let me know if you need anything else."
- Don't ask clarifying questions for small ambiguities — pick the sensible default and proceed.
- Comment code only where logic is genuinely non-obvious. Never add comments that just restate what the line already says.
- Always write and run tests for new logic. Fix failures yourself before reporting done — don't hand back broken code.
- Prefer editing existing files over creating new ones.
- No filler, no hedging, no repeating instructions back.
- After saving, only say: ok
